# am-ml

## Подготовка базы знаний (Task2)

В директории Task2 хранится набор Markdown-файлов, которые составляют корпоративную базу знаний (эпизоды, объекты, технологии и т. д.).

## Построение индекса (Task3)

Для того чтобы документы можно было быстро искать по смыслу, строится векторный индекс.
Проверка индекса возможна с помощью скрипта query.py, который возвращает список ближайших чанков с оценкой сходства и путём к исходнику.
